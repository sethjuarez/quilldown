# Architecture Decision Records

This directory holds Architecture Decision Records (ADRs): short, dated
documents that capture one significant architectural decision each — its
context, the options weighed, the decision, and the consequences. They exist so
the *why* behind a decision is preserved and only revisited deliberately.

Each ADR has a status: **Proposed**, **Accepted**, or **Superseded**.
