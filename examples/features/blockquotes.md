# Block quotes

Block quotes are styled with a left accent border and an indent, so they read as visually
distinct from ordinary paragraphs.

## Simple quote

> The best way to predict the future is to invent it.

Ordinary paragraph after the quote returns to the normal margin.

## Multi-paragraph quote

> First paragraph of a longer quotation that spans several sentences and wraps across more
> than one line so the left border is clearly visible down the whole block.
>
> Second paragraph inside the same quote.

## Quote with inline formatting and a link

> Quotes can contain **bold**, *italic*, `inline code`, and a [link](https://example.com).

## Nested quote

> Outer quote paragraph.
>
> > Nested quote steps further in with a deeper indent.
