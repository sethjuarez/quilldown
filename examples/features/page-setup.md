# Page setup

This document exercises configurable page geometry: size, orientation, and margins. The
table, code block, and horizontal rule below all size themselves to the usable text-column
width, so changing the page size or margins reflows them automatically.

| Setting     | Default | Notes                                  |
|-------------|---------|----------------------------------------|
| Size        | Letter  | `letter`, `a4`, or `legal`             |
| Orientation | Portrait| `portrait` or `landscape`              |
| Margin      | 1 in    | uniform, in inches                     |

```text
Wide code blocks should stretch to fill the content column,
whatever the page size and margins happen to be.
```

---

The rule above spans the same content width as the table and the code block.
